# Best Practice スキル

## 手順

### 1. references を読み込む

`references/claude-code-usage.md` を読み込んで利用可能なテクニックを把握する。

### 2. 現在の作業を分析する

- タスクの種類（実装・リファクタリング・調査・レビュー）
- コードベースの規模と複雑さ
- 繰り返し発生しているパターンや摩擦

### 3. 3つ以内に絞って提案する

多すぎる提案は実践されない。最も効果が高いものを優先する。

提案フォーマット:

```
**<テクニック名>**
なぜ今のコンテキストで有効か: <理由>
やり方: <具体的な手順>
```

## 注意事項

- すでに実践できている部分は提案しない
- ツールや機能の紹介ではなく、現在のタスクへの適用方法を示す
