# Best Practice スキル

## 手順

### 1. references を読み込む

以下の2ファイルを読んで利用可能なテクニックを把握する：

- `references/claude-code-usage.md` — Plan Mode・並列実行・サブエージェント・検証ループ・フック
- `references/prompting-techniques.md` — マイクロマネジメント回避・Challenge パターン・シナリオ別プロンプト

### 2. 現在の作業コンテキストを分析する

以下を確認する：

- **タスク種別**: 実装 / バグ修正 / 調査・リーディング / レビュー / リファクタ
- **作業状況**: 直前のやり取りで繰り返し発生しているパターンや摩擦はあるか
- **未活用の機能**: Plan Mode・並列 Agent・検証ループ・Challenge パターンのどれが使えていないか

### 3. 3つ以内に絞って提案する

多すぎる提案は実践されない。今のコンテキストで最も効果が高いものを優先する。

提案フォーマット：

```
**<テクニック名>**
なぜ今のコンテキストで有効か: <理由>
やり方: <具体的な手順または例示プロンプト>
```

## 注意事項

- すでに実践できている部分は提案しない
- ツールや機能の紹介ではなく、現在のタスクへの適用方法を示す
- このプロジェクト固有のコマンド（`npm run test:unit` など）や `/tdd`・`/ci-debug` との組み合わせを示すと具体性が上がる
