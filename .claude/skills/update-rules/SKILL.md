# Update Rules スキル

## 手順

### 1. 対象を特定する

会話の中から永続化すべき決定・規約・学びを抽出する:

- 「〜の場合は〜する」という判断基準
- 「〜は使わない」という禁止事項
- 「〜の順番でやる」という手順規約

### 2. 配置先を決める

- **横断的なルール**（git、コードスタイル、テスト方針等）→ `.claude/rules/<topic>.md`
- **スキル固有の補足**（ツール選定理由、プロジェクト固有の設定例）→ `.claude/skills/<skill>/references/`

CLAUDE.md との使い分けは `references/claude-rules-spec.md` を参照する。

### 3. 命令形・Why-not スタイルで書く

```markdown
# <トピック>

## <カテゴリ>

- <動詞>こと。（例: コミットメッセージは日本語で書くこと）
- <禁止事項>しないこと。理由: <なぜその選択か>
```

How（どうやるか）は書かない。Why not（なぜその選択か）を書く。

## 注意事項

- 既存のルールファイルがある場合は追記する（上書き禁止）
- CLAUDE.md に既に書かれている内容は重複させない
