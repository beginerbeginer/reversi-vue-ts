# テストファイルの構成規約

## 分割基準

テストファイルが以下のいずれかに該当したら、責務単位でファイルを分割すること：

- **20テスト超**
- **150行超**

## テスト追加時のチェック

テストを追加するときは、追加後のファイルが上記基準を超えないか必ず確認する。
超える場合は**追加前に分割してから**テストを追加する。

## 分割の単位

- `tests/unit/` 配下：テスト対象のクラス・メソッド単位でサブディレクトリを切る
  - 例: `tests/unit/reversi/board.search.spec.ts`
- `tests/integration/` 配下：テスト対象のモジュール・ユースケース単位でファイルを分ける

## Vitest の並列実行

Vitest はファイル単位で独立したワーカーを起動して並列実行する。
ファイルを分割するだけで自動的に並列化され、テスト実行時間が短縮される。
